# Market Stats

FFXIV（Dalamud）向けプラグイン。**リテイナーの販売履歴を購入者ごとに集計**して、
「誰が・何を・いつ・いくつ買ったか」と「同じ人の累計購入数」を一覧で確認できます。

「特定の商品をよく大量購入している人」や「リピーター」を素早く把握することを目的にしています。

---

## 主な機能

- **購入者別の集計** — 購入回数 / 累計購入数 / 累計金額 / 品目数 / 最終購入日時
- **まとめ買いの自動集約** — 同じ人が同じアイテムを続けて買った分を 1 回にまとめて表示

  ```
  ▼ 剛力の宝薬G4   累計 2,475個 / 2回 (枠 25) / 平均 xx ギル
      8/8 20:00    99個 × 15枠    1,485個
      8/5 17:00    99個 × 10枠      990個
  ```

- **取引履歴の一覧** — 日時 / 購入者 / アイテム / 数量 / 単価 / 合計 / リテイナー、および同一購入者の累計
- **Lodestone 連携** — 購入者名をクリックするとキャラクター検索が開きます（自分の DC で絞り込み）
- **ログの保持期間を選択** — 1日 / 3日 / 5日 / 1週間 / 無期限
- **お気に入り購入者** — 登録した購入者のログは長め（2週間 / 1ヶ月 / 3ヶ月 / 無期限）に保持
- **CSV 出力** — 全ログをクリップボードへ
- **Universalis 連携（任意・既定 OFF）** — そのアイテムが今どのワールドでいくらで出品されているか

### 取りこぼし対策

ゲーム内の売却履歴はリテイナー 1 体につき最新 20 件しか残りません。次の機能で取りこぼしを減らせます。

- **AutoRetainer 連携（既定 OFF）** — AutoRetainer の巡回中、各リテイナーの売却履歴を自動で開いて取り込み、すぐ閉じます。巡回のたびに全リテイナー分が取れるので、取りこぼしはほぼ無くなります
- **リテイナーメニューでの自動取得（既定 OFF）** — 自分で話しかけたときにも同じことをします
- **出品リストの差分監視（既定 ON）** — 出品リストから消えた出品を「売れた可能性のある取引」として記録します。購入者名は分かりませんが、履歴が溢れた分の売上も残ります。売却履歴で購入者が判明したら自動的に一覧から外れます
- **取りこぼし警告** — 履歴が 20 件で溢れて記録できなかった区間を検出して表示します

### 出品者と再出品の追跡

- **出品者タブ** — ゲーム内でマーケットボードのアイテムを開くと、その出品を**出品者ごとにまとめて**表示します。マーケットの出品情報にはリテイナー名しか出ませんが、内部的にはオーナーごとの識別子が付いているため、複数リテイナーを使った出品も同一人物としてまとまります
- **出品者名の解決** — 周囲に見えたプレイヤーやフレンド / FC / リンクシェルのメンバーから集めた対応表で、出品者のキャラクター名を表示します。対応表に無い相手は「不明（識別子）」となります
- **その出品者があなたから買っているか** — 対応表で名前が分かった出品者については、あなたのリテイナーからの購入実績を並べて表示します
- **再出品の候補（推定）** — 購入イベントの直後に現れた出品を、時間の近さ・数量パターンの一致・買値より高い値付け・複数回の一致からスコア化して提示します

## 使い方

1. プラグインを有効にする
2. リテイナーに話しかけ、「マーケットに出品する」→ **売却履歴** を開く
3. その時点でゲームが保持している履歴が自動的に取り込まれます
4. `/marketstats`（短縮形 `/mstats`, `/msts`）でウィンドウを開く

| コマンド | 動作 |
|---|---|
| `/marketstats` | ウィンドウの開閉 |
| `/marketstats buyers` | 購入者別タブを開く |
| `/marketstats history` | 取引履歴タブを開く |
| `/marketstats config` | 設定タブを開く |
| `/marketstats dump` | 不具合報告用に内部データをログへ出力 |

## 仕様と制限

このプラグインは **ゲームが持っている売却履歴を読み取って蓄積する** もので、
過去に遡ってデータを取得することはできません。以下の点にご注意ください。

- **ゲーム内の売却履歴はリテイナー 1 体につき最新 20 件のみ**です。
  それより古い分、および前回取り込み以降に 20 件を超えて売れた分は取りこぼします。
  上記の「取りこぼし対策」でかなり減らせますが、ゼロにはなりません。
- **購入者のワールド名は履歴に含まれません。** クロスワールドでも購入されるため、
  Lodestone は「名前＋自分のデータセンター」での検索という形で開きます。
- **マネキン販売など、購入者名が記録されない取引があります。**
  これらは「(購入者不明)」としてまとめて表示されます（設定で非表示にできます）。
- **「購入者がその商品を再出品しているか」を確定することはできません。**
  マーケットの出品情報に出品者のキャラクター名は含まれないためです。
  本プラグインが表示するのは、次の材料を積み上げた**推定**です。
  - 購入した直後（既定 24 時間以内）に、同じアイテムの出品が現れたか
  - 1 枠あたりの数量が購入時と一致するか（990個の購入 → 99個 × 10枠 の出品）
  - 買値より高い価格で出しているか
  - 同じ購入者の複数回の購入に対して、同じ出品者が繰り返し現れるか

  出品者の識別子（オーナー単位）は一意なので「同一人物の出品」は確実にまとまります。
  そこにキャラクター名を結び付ける部分だけが推定です。
  十分な確度で繰り返し一致した場合、その対応を覚えて以後の表示に使います（「推定」と明示されます）。
- **出品者名の解決には対応表が必要です。** 街などで実際に見かけたプレイヤー、フレンド、FC、
  リンクシェルのメンバーが対象で、一度も接点のない相手の名前は分かりません。
  使い続けるほど対応表が育ってヒット率が上がります。

## 保存データ

`%AppData%\XIVLauncher\pluginConfigs\MarketStats\` に保存されます。

| ファイル | 内容 |
|---|---|
| `sales.json` | 取り込んだ売却ログ |
| `favorites.json` | お気に入り登録した購入者 |
| `listings.json` | マーケットで観測した出品（再出品の追跡用） |
| `identities.json` | 出品者の識別子とキャラクター名の対応表 |
| `pending.json` | 購入者不明の売却と、取りこぼし区間の記録 |

売却ログは設定した保持期間を過ぎると自動的に削除されます。
対応表の収集は設定で無効にでき、いつでも消去できます（設定 → データ管理）。

外部に送信されるデータはありません（Universalis 連携を有効にした場合のみ、
照会するアイテム ID とデータセンター名が Universalis へ送信されます）。
収集した対応表や出品記録が外部に送られることはありません。

## ビルド

```
dotnet build -c Release
```

- .NET 10 / Dalamud API Level 15
- Dalamud のライブラリは `%AppData%\XIVLauncher\addon\Hooks\dev` を参照します
